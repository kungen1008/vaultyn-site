## 全局快捷键

在任何 App 里都能用，可以在 **设置 → 全局热键** 里修改。

| 快捷键 | 作用 |
|---|---|
| ⌘ ⌥ P | 打开 / 隐藏 Vaultyn |
| ⌘ ⌥ L | 立即锁定 |

## 在 Vaultyn 里

| 快捷键 | 作用 |
|---|---|
| ⌘ K 或 / | 搜索 |
| ⌘ C | 复制选中条目的密码 |
| ⌘ B | 复制选中条目的账号 |
| ⌘ T | 复制选中条目的验证码 |
| Return | 编辑选中的条目 |
| ⌘ ⌫ | 删除选中的条目（移到回收站） |
| ⌘ S | 编辑时保存 |
| Esc | 取消编辑、关闭弹出的窗口 |
