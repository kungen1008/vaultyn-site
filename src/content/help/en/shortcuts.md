## Global shortcuts

Work from any app; change them in **Settings → Shortcuts**.

| Shortcut | Action |
|---|---|
| ⌘ ⌥ P | Show / hide Vaultyn |
| ⌘ ⌥ L | Lock now |

## Inside Vaultyn

| Shortcut | Action |
|---|---|
| ⌘ K or / | Search |
| ⌘ C | Copy the selected entry’s password |
| ⌘ B | Copy the selected entry’s account |
| ⌘ T | Copy the selected entry’s verification code |
| Return | Edit the selected entry |
| ⌘ ⌫ | Delete the selected entry (moves to Trash) |
| ⌘ S | Save while editing |
| Esc | Cancel editing, close dialogs |
