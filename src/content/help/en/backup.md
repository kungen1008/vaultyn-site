## Automatic backups

Before the first change each day, Vaultyn saves a backup in the `backups` folder inside your data folder. Recent daily, weekly and monthly backups are kept; older ones are deleted automatically.

You can also back up anytime: **Settings → Data & sync → Backup → Back up now**.

## Restore from a backup

- **If Vaultyn opens**: Settings → Data & sync → Backup → Restore from encrypted backup…
- **If it doesn’t** (for example the data is damaged): click **Restore from backup** on the lock screen, choose a file from `backups` and enter the master password you used then.

## Undo a mistake in one entry

No need to restore a whole backup. Open the entry, click **Edit history** and restore an earlier version.
