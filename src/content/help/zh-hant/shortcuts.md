## 全域快速鍵

在任何 App 裡都能用，可以在 **設定 → 全域熱鍵** 裡修改。

| 快速鍵 | 作用 |
|---|---|
| ⌘ ⌥ P | 開啟 / 隱藏 Vaultyn |
| ⌘ ⌥ L | 立即鎖定 |

## 在 Vaultyn 裡

| 快速鍵 | 作用 |
|---|---|
| ⌘ K 或 / | 搜尋 |
| ⌘ C | 複製選中項目的密碼 |
| ⌘ B | 複製選中項目的帳號 |
| ⌘ T | 複製選中項目的驗證碼 |
| Return | 編輯選中的項目 |
| ⌘ ⌫ | 刪除選中的項目（移到回收筒） |
| ⌘ S | 編輯時儲存 |
| Esc | 取消編輯、關閉彈出的視窗 |
